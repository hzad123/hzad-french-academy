# TCF Listening Test03 — original editorial rewrite (v2)

Replaces, but does not delete, Test03 v1. Former v1 remains archived for
existing student attempts and has a separate, immutable media directory.

Test03 v2 was written as 39 individual original French healthcare listening
scenarios, not substituted terms in Test02 or in the old 18-paper templates.
The paper follows the established 39-item format in exactly 35 minutes:
illustrated comprehension, spoken replies, announcements, dialogues, news,
telephone conversation, interviews, panel debate, television, academic
monologue and public lecture, graded from elementary to advanced.

- Four newly illustrated healthcare scenes match the first four audio clips.
- Every question has four plausible alternative answers and one validated key.
- Correct answer placement is randomized and balanced across A–D.
- On-screen correct responses are paraphrases or inferences rather than
  extensive explanations; fuller correction explanations appear only in results.
- All 39 audio files are rerecorded from the same versioned source transcript.
- The new media must be deployed before the private Supabase published pointer
  is updated to v2.
- Existing forward-only / one-listen / auto-advance / Next 1–38 / Submit 39
  engine, 35-minute clock, credits and scoring were not modified.

Automated audio duration, distinct-source, SHA256 and answer-key checks have
passed. The recordings are original text synthesized by local French Piper
speech models; no external paid TTS or student-side AI generation is used.
