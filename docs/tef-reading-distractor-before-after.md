The model used randomized option presentation, saw only the question and four options, and did **not** see the passage, marked answer or explanation. The small sample makes these descriptive diagnostics, not a reliable 25% chance estimate. The question-focus revisions also still need improvement. The passage-aware reviewer accepted exactly one supported answer for all 12 in the second pilot, but only 8/12 passed the complete grounded-distractor/quotes checks.

## Release rule

No candidate becomes the current live paper merely because its wording is better. Every revised question must pass an independent answer-only review and an independently keyed passage-grounded reviewer, and the balanced cohort sample must demonstrate that superficial guessing no longer has a consistent advantage. Failing items remain blocked in the draft branch. Existing production attempts and question versions remain untouched.
